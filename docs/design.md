## [공통 블록] — 모든 프롬프트 맨 앞에 붙임

모바일 웹 서비스 "새우맵" 화면을 디자인해줘. 390×844 모바일 프레임, 라이트 모드.

**서비스**: 서울 새우구이 가게 지도. 야장맵·거지맵 같은 사용자 참여형 지도. 크롤링한 421곳으로 시작하고, 사용자가 "다녀왔다면" 확인·리뷰·제보로 갱신한다.

**무드**: 캐치테이블·테이블링 계열의 담백한 정보형. 2026년 한국 앱 트렌드. AI가 만든 티가 나면 실패다.

**스타일 규칙** (2026-09-02 리디자인 — 버틸까 디자인 언어. 토큰 표는 아래)
- 바탕: 화이트/쿨 뉴트럴 그레이(#191F28 계열 램프). 텍스트는 잉크(gray-900).
- 브랜드 새우 레드 #F04A28 — **채운 레드 버튼은 화면당 딱 한 곳**([+ 제보] 같은 주 액션). 활성 칩·라벨은 레드 **틴트**(연한 배경 red-10 + red-600 보더·글자), 클러스터 마커는 레드 원. 그 외 남발 금지.
- 카테고리 색: 소금구이(구이) = 코랄 #F0885C, 생새우회(회) = 틸 #14957B. 카드의 색점(6px)과 마커 링에만. 배경 칠하기 금지. 화면 라벨은 "소금구이"·"생새우회".
- 폰트: Pretendard Variable, 자간 -2%, 행간 140%. 텍스트 스타일 12종(Title/Body/Caption × 굵기)만 쓴다. 가격·거리·단위 숫자는 tabular numbers.
- 라운드: 6(미니칩) / 8(입력·컨트롤) / 12(카드·트랙·토스트) / 20(시트 상단) / pill(칩·FAB). 임의 라운드 금지.
- 보더는 헤어라인(gray-100·200). 그림자는 지도 위에 뜨는 요소와 시트 상단에만 옅게(float/upper/fab/marker 4종).
- 칩: pill 아웃라인 기본, 활성만 레드 틴트. 정렬·탭 전환은 세그먼트(가라앉은 트랙 + 흰 활성 세그먼트).
- 아이콘: 얇은 라인 아이콘(coolicons). 이모지 금지.
- 지도 위에는 검색 블록과 칩 행 **두 층만** 띄운다. 로고·카운터·이벤트·주 버튼은 지도 위에 두지 않는다(시트로). 마커: 클러스터 = 레드 원 + 가게 수, 개별 핀 = 썸네일 원 + 카테고리색 링(썸네일 없으면 회색 원 안 카테고리 색점). 새우 로고·마커 아이콘 에셋은 아직 없음.

**금지 (AI티)**: 크림+세리프 조합, 카드마다 색 띠, 이모지 섹션 헤더, 전면 라운드, 그라데이션 배경, 보라색.

## [화면 1] 지도 메인

위 공통 블록에 이어서:

풀스크린 지도 위에 **두 층만** 얹힌 메인 화면. 지도는 밝은 회색 톤 플레이스홀더(네이버지도 느낌)로 두고 마커만 표시.

위에서 아래로:
1. 검색 블록 — 상태바 아래 흰 배경 블록 안에 회색(gray-100) 입력 하나: 돋보기 + "가게·동네 검색". 로고·버튼 없음. 블록 아래 옅은 그림자.
2. 칩 행 — 블록 아래 10px, 지도 위에 떠 있는 pill 한 줄: **[전체 ▾] 드롭다운 칩**(누르면 아래에 흰 카드 목록 전체 / 소금구이 / 생새우회, 선택하면 칩이 레드 틴트 "소금구이 ▾") + 토글 pill 5개 [머리버터구이] [라면] [볶음밥] [새로 들어온 집] [찜한 곳](흰 아웃라인, 켜면 틴트, AND). 칩 행 전체가 넘치면 함께 가로 스크롤(드롭다운 칩도 같이 넘어감). 사이드 칩을 켰는데 0곳이면 시트에 "조건에 맞는 집이 없어요 · 칩을 풀거나 지도를 옮겨보세요" + [필터 해제].
3. FAB 줄 — 바텀시트 가장자리 바로 위: **왼쪽** 흰 원(40px) 현위치 버튼(표적 모양 아이콘), **오른쪽** [＋ 제보] 레드 pill(화면의 유일한 채운 레드).
4. 바텀시트(화면 40% 올라온 상태) — 상단 라운드 20, 위로 뜨는 옅은 그림자, 핸들(50×6 회색). 헤더 한 줄: 제목 "마포구 일대 12곳"(20 semibold) 왼쪽 + 정렬 텍스트 트리거 "가까운순 ▾"(14 회색, 누르면 작은 목록) 오른쪽. 그 아래 캡션(12 회색): 초록 라이브 점 + "오늘 6건 확인됐어요 │ 이번 주 47곳"(구분은 세로 헤어라인, 숫자만 진하게). 아래 헤어라인.
5. 이벤트 행 — 시트 본문 맨 위, 공지 행 문법: 왼쪽 32px 레드 틴트 원 안 선물 아이콘 + 제목 "새우 까주기 테스트"(14 semibold) / 부제 "당신은 까주는 쪽?"(12 회색) + 오른쪽 닫기 × 하나. 행 전체가 링크(화살표 없음), 아래 헤어라인. em dash·가운데 점 같은 기호로 문장을 잇지 않는다.
6. (정렬 세그먼트는 없음 — 헤더 트리거로 대체)
7. 카드 리스트(2.5장 보임, 헤어라인 구분) — 카드 한 장: **왼쪽 64px 라운드 12 썸네일**(사진 없으면 회색 타일 가운데 카테고리 색점 — 마커 플레이스홀더와 같은 톤) + 오른쪽: 상호(16 semibold) / 오른쪽 끝 "어제 확인"(12 회색) / 메타 "**850m** · 마포구 · 소금구이 · 생새우회"(12 회색, 거리만 진하게 — 내 위치 없으면 지도 중심 기준) / 사이드 미니 pill(머리버터구이·라면). 메뉴·가격·평점은 카드에 없음(가격은 상세, 평점은 리뷰 3개 이상일 때만 나중에). 수성2호에는 "새로 제보됨" 레드 틴트 라벨.
8. 지도 마커 — 멀리: 레드 원 안에 가게 수("20"). 가까이: 36px 원에 가게 썸네일 + 카테고리색 링(코랄 5·틸 2), 썸네일 없으면 회색 원 안 카테고리 색점. 그중 1개는 점선 링(새로 제보됨), 하나는 선택 상태(확대 + 잉크 링).

샘플 데이터의 나라수산, 365활새우 창우수산, 수성2호를 카드로.

## [화면 2] 가게 상세 (바텀시트 전체 펼침) (v1 초안 — 착수 시 v2로 재작성)

위 공통 블록에 이어서:

지도 메인에서 카드를 탭해 바텀시트가 전체로 펼쳐진 상세 화면. 지도는 상단에 조금만 보임.

위에서 아래로 (이 순서 엄수):
1. 사진 영역 — **빈 상태가 기본**: 점선 박스, 카메라 라인 아이콘, "아직 사진이 없어요", [+ 첫 사진 올리기] 텍스트 버튼, 아래 작게 "네이버에서 사진 보기" 링크.
2. 상호 "나라수산" (크게) + 카테고리 색점 2개(코랄·틸) + "구이 · 회" 텍스트 태그.
3. 확인 줄 — 체크 아이콘 "어제 확인됨 · 2026.08.27" + 오른쪽에 "다녀왔다면 →" (액센트 레드 텍스트, 화면의 유일한 레드).
4. 주소 — "서울 마포구 마포대로12길 34" + 지번 회색 + [복사] 작은 버튼.
5. 영업시간 — "영업 중 · 23:00 라스트오더 · 월 휴무" (영업 중은 초록 텍스트).
6. 버튼 줄 — [길찾기](진한 잉크색 채움, 주 버튼) [공유] [♡ 찜] 아웃라인.
7. 대표 메뉴 — 구분선 리스트: "생새우소금구이 [1kg] 60,000" / "새우회 반반 [1kg] 55,000" / "새우 머리구이 3,000". 단위는 회색 칩, 가격 오른쪽 정렬. 리스트 끝에 "가격이 달라졌나요? · 수정 제안" 회색 링크.
8. 사이드 — 칩 3개: [머리버터구이] [라면] 활성(잉크색 아웃라인+아이콘), [볶음밥] 회색 비활성.
9. 리뷰 — 섹션 타이틀 "리뷰" + 빈 상태: 별 5개 회색, "아직 리뷰가 없어요 · 첫 방문자가 되어보세요", [리뷰 남기기] 버튼(잉크색).
10. 맨 아래 한 줄 회색 작은 링크: "정보 수정 제안 · 신고 · 사장님이신가요?"

변형 요청(같은 세션에서): (a) 사진 3장 있는 버전 — 가로 스크롤 썸네일, (b) 신규 핀 버전 — 2번 아래에 옅은 배경 배너 "새로 제보된 곳이에요 · 다녀오셨다면 확인해주세요".

## [화면 3] 제보 플로우 (4단계 + 완료, 프레임 5장) (v1 초안 — 착수 시 v2로 재작성)

위 공통 블록에 이어서:

바텀시트 안에서 진행되는 제보 플로우. 상단에 단계 표시(1/4 형태의 얇은 진행바), 뒤로가기 화살표.

**프레임 1 — 가게 찾기**: 큰 검색창 "가게 이름을 검색해주세요" + 자동완성 리스트에 우리 DB 매치 2개("수성2호왕새우소금구이 · 관악구 · 이미 새우맵에 있어요" 라벨) + 맨 아래 "찾는 가게가 없나요? → 새로 등록하기" 버튼.

**프레임 2 — 위치**: 지도(현 위치 중심)에 드래그 가능한 핀 1개, 하단 "핀을 가게 위치로 옮겨주세요" + 주소 검색 입력 보조 + [여기가 맞아요] 버튼(액센트 레드). 위쪽에 작은 경고 카드 변형: "150m 안에 비슷한 가게가 있어요 — 청춘조개포차 신촌점 [이 가게예요] [다른 가게예요]".

**프레임 3 — 메뉴와 가격**: 입력 줄 — 메뉴명 "왕새우소금구이", 가격 "45,000", 단위 칩 선택([1kg] [500g] [한판] 활성 [반판] [기타]). 아래 토글 "새우회도 팔아요" 꺼진 상태. [다음] 버튼.

**프레임 4 — 선택 항목**: 사진 추가 박스(점선), 사이드 체크 3개, 영업시간 메모 입력 "예: 새벽 2시까지, 월 휴무". 제일 큰 버튼이 [건너뛰고 등록](잉크색), 그 위에 작게 [입력하고 등록].

**프레임 5 — 완료**: 체크 애니메이션 자리, "등록됐어요! 지도에 바로 보여요", "7일간 '새로 제보됨' 표시가 붙어요" 설명, [내 핀 보러가기] 주 버튼 + [카카오톡으로 공유] 아웃라인 + "리뷰도 남겨볼래요?" 링크.

## [화면 4] 새로 들어온 집 패널 (v1 초안 — 착수 시 v2로 재작성)

## [화면 6] 데스크탑 — 지도 메인 (좌측 패널 + 지도) (v1 초안 — 착수 시 v2로 재작성)

위 공통 블록에 이어서 (1440×900 데스크탑 프레임):

거지맵·카카오맵 PC 문법. 새 화면이 아니라 모바일 내용물의 그릇을 바꾼 것.

- **왼쪽 고정 패널 400px**, 위에서 아래로:
  1. 헤더 — "새우맵" 로고 텍스트 / 오른쪽 [+ 제보](액센트 레드, 화면 유일 레드)
  2. 검색바 "가게·동네 검색"
  3. 시즌 카운터 한 줄 "이번 주 확인 47곳 · 오늘 12건"
  4. 탭 [전체][구이][회] + 칩 [새로 들어온 집][찜한 곳] — 두 줄
  5. 리스트 헤더 — "지도 내 12곳" / 정렬 "가까운순 ▾"
  6. 카드 리스트 (패널 내부만 스크롤, 카드 4장 보임) — 카드 구성은 모바일과 동일: 상호/구·거리/색점/메뉴 한 줄+단위칩+가격/사이드 미니칩/"어제 확인"
  7. 패널 맨 아래 고정 얇은 줄 — "새우맵 소개 · 사장님이신가요?" 회색 링크
- **오른쪽 전체 = 지도** (밝은 회색 플레이스홀더): 마커 10여 개(코랄 7·틸 3, 점선 테두리 1), 우하단 줌·현위치 컨트롤, 좌하단 지도 출처 표기 자리.
- **상호작용 상태를 그려줘**: 카드 하나 호버 — 카드 배경 옅어지고 지도의 해당 마커가 커짐. 마커 하나 호버 — 위에 작은 툴팁 "나라수산 · 생새우소금구이 1kg 60,000".
- 패널과 지도 사이 헤어라인. 지도 위에 플로팅 요소 두지 않기(검색·칩 전부 패널 안).

변형 요청: (a) 이벤트 카드가 패널 3번 아래 끼어든 버전, (b) 검색 결과 0곳 — 리스트 빈 상태 "이 동네엔 아직 없어요 · 제보해주세요 [+ 제보]".

## [화면 7] 데스크탑 — 상세 (패널 전환) (v1 초안 — 착수 시 v2로 재작성)

위 공통 블록에 이어서 (1440×900):

[화면 6]에서 카드를 클릭한 상태. 왼쪽 패널이 상세로 전환되고, 지도는 해당 마커가 선택 상태(크게 + 살짝 어두운 링).

- 패널 상단: ← 뒤로 (누르면 리스트로) + 오른쪽 공유·찜 아이콘.
- 이하 [화면 2]의 1~10 순서 그대로, 400px 폭에 맞게:
  - 사진 빈 상태 박스는 패널 폭 꽉, 높이 160px 정도. 사진 있으면 2열 그리드 썸네일.
  - 확인 줄·주소·영업시간은 한 줄씩.
  - 버튼 줄 [길찾기][공유][찜]은 3등분.
  - 메뉴 리스트·사이드·리뷰 빈 상태·하단 링크 줄까지 전부 포함. 패널 내부 스크롤.
- "다녀왔다면 →"이 이 화면의 유일한 레드.
- 지도 쪽: 선택 마커 옆에 작은 카드 팝오버는 그리지 않기(패널이 상세니까 중복). 선택 마커 강조만.

변형 요청: 신규 핀 버전 — 상호 아래 옅은 배너 "새로 제보된 곳이에요 · 다녀오셨다면 확인해주세요".
