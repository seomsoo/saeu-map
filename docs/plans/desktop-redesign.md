# 데스크탑 리디자인 — 떠 있는 패널 · 지도 위 칩 · 혼합 카드 (design 화면 6~9 v3)

## Context

Phase 5(2026-09-07)로 데스크탑 그릇이 생겼다. 지금 상태: 1024px부터 **왼쪽 400px 흰 패널이 지도에 붙어 있고**(오른쪽 헤어라인), 검색 바·칩 행이 전부 패널 안, 지도 위엔 우하단 줌·현위치뿐. 카드는 모바일 그대로(썸네일 64 + 상호 + 메타 한 줄), 사진이 없으면 새우 플레이스홀더가 연속으로 깔린다. 그 다음 `feat/assets-desktop`에서 새우 에셋(마커·파비콘·별점 새우·OG 아트)이 들어갔고, 이 브랜치에 아직 PR을 올리지 않았다.

사용자 판단: **"모바일 디자인을 그대로 패널에 넣은 그릇이라 밋밋하다."** 넓은 화면을 쓰고 싶고, 칩은 네이버지도 PC처럼 밖(지도 위)으로, 정보는 더.(접기도 요청받아 만들었지만 눌러 본 뒤 뺐다 — 결정 표 참조) 이번 작업은 **에셋 커밋과 같은 PR로 올린다**.

시안 4벌을 `.playwright-mcp/siann.html`(로컬 전용, gitignored)에 그려 비교했다 — A 정석 확장 / B 플로팅 / C 2열 매거진 / **D 플로팅 뼈대 + 매거진 요소**. D 채택.

**패키지 추가 없음.** Next 16.3.3 · React 19.2 · Tailwind 4.3.3 · vitest 4.1 그대로. 새 에셋은 워드마크 PNG 1장(사용자 제작, 투명 배경으로 재전달 예정).

## 디자인 언어 — 화면 6~9 v3 (전문은 design.md에 쓴다; 1440×900 기준, 1024부터)

- **그릇**: 지도가 뷰포트 전체. 패널은 그 위에 뜬 카드 — `left/top/bottom: 16`, `w-105`(420), `rounded-20`, `shadow-panel`(신규 토큰 `0 4px 32px 0 rgb(0 0 0/.14)`), 내부만 스크롤. 세로 헤어라인 없음.
- **패널 순서**: 브랜드 줄(44 — 워드마크 / 고스트 [＋제보]) → 검색 바(44 pill, 헤어라인, 그림자 없음, 오른쪽 끝 프로필) → 헤드라인("서울 전체 **41곳**" 25 bold, 자간 -3.5%) + 카운터 캡션(오늘 확인 · 이번 주 N곳 · 새로 들어온 집 N곳) → 정렬 세그먼트(pill 3칸, 활성만 흰 배경 + shadow-float) → 이벤트 배너 → 카드 리스트 → 목록 끝 [아는 새우집 제보하기](채운 레드, 라운드 12, 높이 46).
- **카드 2종**(같은 컴포넌트, 사진 유무로 분기):
  - **사진 카드** — 16:9 라운드 12 사진(우상단 하트 28 원), 제목 17 semibold + 오른쪽 확인 라벨, 메타(거리 굵게 · 구 · 카테고리 │ 노선 배지 + 역 + 거리), 가격 15 semibold + 메뉴명 12.5 회색, 칩 + 평점. 안쪽 여백 18/22/22.
  - **콤팩트 행** — 썸네일 72 라운드 12(플레이스홀더 새우 44), 같은 정보 세트를 한 단 낮춘 크기로. 패딩 16/22.
  - 선택 `bg-bg-sunken`, hover `bg-bg-dim`(현행 유지).
- **이벤트 배너**: `bg-brand-tint` 라운드 16, 제목 15 semibold `brand-fg` / 부제 12.5, 오른쪽에 새우 아트 92 `rotate(-12deg)` 걸침, 닫기 ✕는 흰 70% 원 22. 행 전체 링크(화살표 없음 — 기존 결정 유지).
- **지도 위**: 칩 행 한 층(pill, 활성만 브랜드 틴트) + 우하단 줌·현위치(현행). 마커·클러스터 규칙은 화면 1 그대로.
- **모바일(<1024)**: 지금 그대로 — 떠 있는 검색 pill + 칩 행 두 층 + 바텀시트. 카드만 사진 유무 분기를 공유한다(사진이 있으면 모바일도 사진 카드 — *열린 질문 1*).

## 변경

### 1. 문서 먼저 — `docs/design.md` · `docs/decisions.md` · `CLAUDE.md`

- design.md 화면 6~9를 **v3로 재작성**(위 언어). 화면 1의 카드 블록에 "사진 있으면 사진 카드" 분기 추가.
- decisions.md에 **뒤집기 3건** 기록: ① 데스크탑 "지도 위에 뜨는 UI 없음"(2026-09-07) → **칩 한 층은 지도 위**(전제가 바뀌었다: 패널이 떠 있는 카드가 되면서 패널 안 칩 두 줄이 세로를 먹고 지도가 좁아 보였다). ② 붙은 패널 400 → 떠 있는 420. ③ 브랜드 행 채운 레드 [＋제보] → 고스트 + 목록 끝 CTA.
- CLAUDE.md 스타일 줄의 "지도 위에는 검색 바·칩 행 두 층만"이 **모바일 규칙**임을 명시하고 데스크탑 줄(칩 한 층, 검색은 패널)을 덧붙인다. roadmap Phase 5 결과 줄에 이 플랜 링크.

### 2. 토큰 · 커서 — `app/globals.css`

- `--shadow-panel` 추가(떠 있는 패널). 기존 shadow 토큰은 그대로.
- base 레이어에 버튼 커서 규칙(위 결정). 비활성 버튼은 제외.
- 데스크탑 블록(`@variant lg`)에서 `.saeu-sheet`의 fixed·transform 해제 규칙을 **떠 있는 패널**에 맞게 조정.

### 3. 그릇 — `components/map-screen/map-screen.tsx` · `lib/layout.ts` · `use-map-screen.ts`

- 래퍼에서 `lg:flex` 제거. 지도는 모바일과 같이 `absolute inset-0`, 패널 래퍼는 모바일 `contents` → `lg:absolute lg:inset-y-4 lg:left-4 lg:w-105 lg:z-10 lg:rounded-20 lg:shadow-panel`.
- **지도 기하 보정(중요)**: 패널이 지도 위에 겹치므로 선택 마커가 패널 뒤로 숨을 수 있다. `lib/layout.ts`에 `PANEL_INSET_PX`·`PANEL_WIDTH_PX`·`PANEL_OCCLUSION_PX`를 두고(CSS의 `lg:left-4`·`lg:w-105`와 같은 값), `MapHandle.panTo`·`focus`에 `screenX`를 더해 데스크탑에서만 가로를 보정하고 `fitBounds`는 왼쪽 마진을 그만큼 더 준다.
- 토스트는 그릇별로 나눠 단다 — 떠 있는 패널이 `absolute`라 그 안에 두면 "화면 아래 가운데"가 패널 기준이 된다.

### 4. 지도 위 칩 층 분리 — `map-screen.tsx`

- 지금 한 덩어리인 상단 스택(검색+칩)을 **검색 바(패널 안)** 와 **칩 행(지도 위 레이어)** 으로 나눈다.
- 모바일 회귀 주의: 나뉜 뒤에도 모바일에서는 검색 pill 아래에 칩 행이 같은 간격으로 떠야 한다. 칩 행 `top`을 safe-area + 검색 바 높이 + gap으로 고정하고, 시트 스냅 계산이 쓰는 `topStackRef` 높이가 여전히 두 층을 포함하는지 확인(390×702·656·320×480 실측).

### 5. 패널 내용 — `place-sheet.tsx` · `search-bar.tsx` · `event-card.tsx` · `components/ui/segmented.tsx`

- 브랜드 줄(워드마크 + 고스트 제보), 헤드라인·카운터, 정렬 세그먼트(데스크탑만 — 기존 `Segmented` 재사용), 이벤트 배너, 목록 끝 채운 CTA.
- 여백 리듬(22 / 8·14·20)과 카드 구분선 제거.

### 6. 카드 — `place-card.tsx` · `lib/data.ts` · `lib/places.ts`

- 사진 유무 분기(사진 카드 / 콤팩트 행), 가격 줄(`primaryMenuLine` 재사용), 역 배지(`subway-badge` 재사용), 하트(익명도 토글 가능 — 넛지만 뜬다), 평점.
- **평점은 데이터 경유**(규칙 1): `lib/data.ts`에 핀별 리뷰 집계(평균·개수, 3개 미만은 null)를 추가해 목록이 그것만 읽는다. Phase 6에서 이 함수만 Supabase 집계로 교체.

### 7. hover 사진 프리뷰 — `map-view.tsx` · `use-map-screen.ts`

- 기존 툴팁을 사진 있는 집만 사진 카드로 확장. 진입 150ms / 이탈 300ms 타이머, 가장자리 플립, `dragstart`·`zoom_changed`에 즉시 닫힘, 클러스터 제외. 타이머는 언마운트·모드 전환에서 정리(alive 규칙).

### 8. 에셋 — `public/`

- 워드마크(투명 배경, 브랜드 레드 반영본)를 트림 + 2x WebP(높이 ~52)로 `public/wordmark.webp`. `<h1>` 안 `<img alt="새우맵">`로 넣어 SEO·접근성 유지.
- decisions.md "커스텀 에셋 필요 목록"에서 **워드마크 줄 삭제**(3줄 → 2줄).

### 9. 보정 + 감사 + PR

- 갭 스윕(gap-sweeper)으로 design 화면 1·6~9 전수 대조, security-reviewer(쓰기 경로 변화 없음이지만 카드 하트가 늘어 확인), `pnpm typecheck && pnpm lint && pnpm test`.
- 에셋 커밋들과 함께 PR 하나로.

1. `docs`: design 화면 6~9 v3 + decisions 뒤집기 3건 + CLAUDE.md·roadmap 정정
2. `fix`: 버튼 커서 pointer(Tailwind v4 Preflight 대응) + `--shadow-panel` 토큰
3. `feat`: 떠 있는 패널 그릇 + 지도 기하 오프셋(패널 폭만큼 가로 보정)
4. `feat`: 칩 행 지도 위로 / 검색 바 패널 안으로 (모바일 회귀 확인 포함)
5. `feat`: 패널 내용(브랜드 줄·헤드라인·세그먼트·이벤트 배너·목록 끝 CTA) + 여백 리듬
6. `feat`: 혼합 카드(사진/콤팩트) + 가격·역·평점·하트 + 평점 집계(lib/data)
7. `feat`: hover 사진 프리뷰
8. `feat`: 워드마크 에셋
9. `chore`: 갭 스윕·보정·PR
